REVIEW DRAFT. Not a label, Safety Data Sheet or application recommendation.

A combined liquid trace blend.
Opti-Trace Complete combines Manganese, Zinc, Iron, Copper and Molybdenum in a liquid formulation.
It is a fixed combination to assess where more than one of these trace Elements is required during crop growth.

Overview
Opti-Trace Complete supplies Manganese, Zinc, Iron, Copper and Molybdenum in a liquid blend. It provides a combined option when several of these trace Elements need attention at the same time.
A mixed blend is useful only when its contribution matches the requirement. Plant results and previous applications help the agronomist decide between Complete, a targeted trace correction and a custom liquid prescription.
